1.- clonar el repositorio.

2.- en consola: composer install.

4.- renombrar el archivo ".env.example" a ".env" (aca debe ir configuracion de base de datos)

5.- en consola ejecutar:
php artisan key:generate
php artisan migrate
php artisan db:seed (esto cargara en base de datos comunas y sus codigos, como tambien algunos establecimientos)

5.- npm i

6.- npm run build para compilar assets
